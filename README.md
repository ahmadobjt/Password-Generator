Password Generator
A simple password generator made with Python. It allows the user to choose the password length and the types of characters to use.

Features
- Choose the password length
- Use lowercase letters
- Use uppercase letters
- Use numbers
- Use special characters
- Use all character types together
- Generates a random password
- Checks for valid user input

Technology
- Python

How to Run
1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

python password_gen.py

4. Enter the desired password length.
5. Select the character types.
6. The generated password will be displayed.

Purpose
This project was created to practice Python functions, user input, loops, conditions, string handling, and random password generation.
